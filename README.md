# GEO (Generative Engine Optimization)

**English** | [Português](README_pt.md)

GEO is **"SEO for AI"**.

- In **SEO**, the goal is to rank well in Google's list of links.
- In **GEO**, the goal is for your brand to be **cited or recommended inside the answer** that ChatGPT, Gemini, Perplexity or Claude writes for the user.

## The 3 principles

> **Understand → Track → Expand**

The three work as a continuous cycle: we measure how the brand shows up today, take action to improve it, and track whether those actions worked.

### 1. Understand (Measure)

To understand the answers, we simulate the user's interface: we ask the same questions the user would ask, in the same AIs, and analyze what comes back.

For each answer, we measure:

| Metric        | Question it answers                                  |
| ------------- | ---------------------------------------------------- |
| **Mention**   | Does the brand appear in the answer?                 |
| **Position**  | Does it appear first, fourth or somewhere else?      |
| **Sentiment** | Does the AI speak well or badly of it?               |
| **Sources**   | Which websites did the AI cite to build the answer?  |

From the sources, we map **patterns**: which websites appear most often and have the most influence on the answers.

### 2. Track

Analyze the results as they come in over time and evaluate the strategies based on them: what worked, what didn't, and what needs to be adjusted.

### 3. Expand

Based on the analyses, define action strategies to improve the brand's presence **in the sources** and, as a result, **in the AI answers**.

## Example questions

- "Best pizzerias in São Paulo"
- "AdX with low fees for publishers"
- etc.

## How it works in practice

For each project, we run **X frequently asked questions** across **Y generative AIs** to:

1. **UNDERSTAND** the metrics;
2. **TRACK** the results of the strategies;
3. **EXPAND** the brand's presence.
