# GEO (Generative Engine Optimization)

[English](README.md) | **Português**

GEO é o **"SEO das IAs"**.

- No **SEO**, a meta é aparecer bem posicionado na lista de links do Google.
- No **GEO**, a meta é a sua marca ser **citada ou recomendada dentro da resposta** que o ChatGPT, o Gemini, o Perplexity ou o Claude escrevem para o usuário.

## Os 3 princípios

> **Entender → Acompanhar → Ampliar**

Os três funcionam como um ciclo contínuo: medimos como a marca aparece hoje, agimos para melhorar e acompanhamos se as ações deram resultado.

### 1. Entender (Medir)

Para entender as respostas, simulamos a interface do usuário: fazemos as mesmas perguntas que ele faria, nas mesmas IAs, e analisamos o que volta.

Em cada resposta, medimos:

| Métrica        | Pergunta que responde                                    |
| -------------- | -------------------------------------------------------- |
| **Menção**     | A marca aparece na resposta?                             |
| **Posição**    | Aparece em primeiro, em quarto ou em outra posição?      |
| **Sentimento** | A IA fala bem ou mal dela?                               |
| **Fontes**     | Quais sites a IA citou para montar a resposta?           |

A partir das fontes, mapeamos **padrões**: quais sites aparecem com mais frequência e influenciam mais as respostas.

### 2. Acompanhar

Analisar os resultados que forem chegando ao longo do tempo e avaliar as estratégias com base neles: o que funcionou, o que não funcionou e o que precisa ser ajustado.

### 3. Ampliar

Com base nas análises, definir estratégias de ação para melhorar a presença da marca **nas fontes** e, consequentemente, **nas respostas das IAs**.

## Exemplos de perguntas

- "Melhores pizzarias em São Paulo"
- "AdX com taxas baixas para publishers"
- etc.

## Como funciona na prática

Para cada projeto, rodamos **X perguntas frequentes** em **Y IAs generativas** para:

1. **ENTENDER** as métricas;
2. **ACOMPANHAR** os resultados das estratégias;
3. **AMPLIAR** a presença da marca.
